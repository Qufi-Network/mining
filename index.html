What a Q is

A unit of Proof of Contribution

A Q is a digital unit the network gives for Proof of Contribution. It records one thing: a Palm node was online and doing its job for a whole day. Qs are not tokens, and no two are the same.

One day online

Each Q stands for one day a Palm node stayed online. A node online for a year has 365 of them.

Non-fungible

Every Q is tied to the node that earned it and the day it records, so no Q is interchangeable with another.

Not a token

A Q is a record of contribution given by the network, not a token, a coin or a security, and not a claim on anything.

Proof of Contribution

What is Proof of Contribution?

Proof of Contribution is how the QuFi network recognises the work that keeps it running. A network only works if its nodes are there when they are needed. Proof of Contribution measures exactly that, proves it with a key inside each phone, and records each day of it as one Q.

You contribute by being there. The network proves you were there. A Q records that you were.

Proof of Contribution, in one line
Contribute, prove, record
  1. 01

    Contribute

    A Palm node stays online, ready to check palm approvals and sign Palm payments whenever a vault needs it.

  2. 02

    Prove

    Every few minutes the node answers the network with a heartbeat signed by a key locked in the phone’s security chip. It cannot be faked from a server or answered for someone else.

  3. 03

    Record

    At the end of each day the network gives one Q to every node that proved it stayed online. The Q is a permanent record of that day.

Proven, not claimed

Contribution counts only when the phone’s own hardware key proves it.

The same for every node

One Q per node per day online. Every node is measured by the same rule.

Not bought

Money, bigger servers or holding Qs earn nothing. Only a day online does.

Open to check

Anyone can check from public data which node was online on which day.

Compared with mining and staking

One day online, one Q

Proof of work rewards computing power. Proof of stake rewards money locked up. Proof of Contribution counts the thing the Palm network actually runs on: Palm nodes that stay online, each one proven by a key inside the phone.

Being online is the work

Staying reachable is what keeps Palm vaults able to sign. Nothing is burned to mine a Q.

Every day is proven

Each heartbeat is signed by a key in the phone's security chip, so it cannot be made in advance or copied to another device.

The same for every node

One Q per node per online day. No draw and no luck: more money or more servers buy no extra Q for a node.

How it works

Four steps, every day

Mining runs on the Palm nodes that already sign Palm payments. Staying online is the work.

One day
  1. 01

    Stay online

    The Palm node app sends a signed heartbeat every 5 minutes from the phone.

  2. 02

    Checked all day

    Each heartbeat is checked against the node's own hardware key, so no one can answer for it.

  3. 03

    The day closes

    At the end of the day the network counts which nodes stayed online.

  4. 04

    1 Q credited

    Every node that stayed online receives one Q. Anyone can check it from public data.

Who mines

Three checks, every day

A node mines its Q for the day only when all three hold. Uptime is the easiest thing to fake, so each day has to be proven by one real phone running one licensed node.

A Palm node licence

The phone joined with an invite or licence signed by the network key.

A real phone

Its key lives in the phone's security chip, proven by Android Key Attestation. Emulators and servers cannot fake that proof.

Online for the day

A heartbeat in every 5 minute slot of the day, with up to 10 minutes of grace for a network blip.

Supply

Ten years, 73 million Q

20,000 Palm nodes × 365 days × 10 years = 73,000,000 Q. That is the most there can ever be: fewer nodes online means fewer Q. Each year the treasury, funded by half of every Palm fee, buys back 7.3 million Q and burns it, the same as the most that can be mined in a year.
